# Pizza Ordering Program
A simple C++ console application that allows a user to create a pizza order.

##Features

-Select number of pizzas
-Input validation for incorrect quantities
-Select number of toppings
-Choose toppings from a menu
- Uses arrays to store topping options

#Concepts Practiced

-Variables
-User Input/Output
- While loops
- Input Validation
- Arrays
- Conditional logic

  ##Built with

  C++
